# Hadeed Sentient Platform (V5.0 - The Masterpiece)

مستودع مشروع **Hadeed Sentient Platform**، المنصة الثورية للكشف عن المعادن المدعومة بالذكاء الاصطناعي الواعي. هذا المشروع يمثل قفزة نوعية من مجرد "جهاز كشف" إلى "رفيق ذكي" يتعلم، يتفاعل، ويحمي المستخدم.

## فلسفة المشروع
> "Software-Defined, Autonomous, Emotionally Intelligent Metal Detection. جهاز يتصرف كرفيق واعي، بزر واحد وشاشة قيادة ذكية، يتعلم محلياً، ويتعافى من الأخطاء صمتاً."

## الركائز الأساسية (V5.0)

### 1. واجهة المستخدم الفيزيائية (UI Paradigm)
*   **زر واحد مخفي**: تصميم بسيط لمنع أعطال الرمل والماء (IP68).
*   **شاشة Transflective LCD**: وضوح فائق تحت شمس الصحراء تعرض المعلومات الجوهرية فقط.
*   **حلقة إضاءة تكتيكية RGB**: لتوفير تغذية راجعة بصرية سريعة.

### 2. العمارة البرمجية الخماسية الطبقات
*   **Layer 1 (Drivers)**: محرك Zero-Latency باستخدام DMA لنقل البيانات اللحظي.
*   **Layer 2 (DSP)**: خوارزميات متقدمة مثل Adaptive Kalman Filter و 2D-FFT لاختراق قناع الحديد.
*   **Layer 3 (AI Auto-Pilot)**: نظام TinyML للتصنيف اللحظي ومحرك التعافي الذاتي (Self-Healing).
*   **Layer 4 (BLE)**: نظام مصافحة ذكي وتحديث هوائي مزدوج (Dual Bank OTA).
*   **Layer 5 (App)**: تطبيق مرافق يعمل كخدمة خلفية (Foreground Service) لضمان الاستمرارية.

### 3. الذكاء العاطفي الاصطناعي (EQ)
*   **محرك التعاطف الديناميكي**: نصوص متغيرة للتفاعل مع المستخدم دون إزعاج.
*   **Dynamic Verbosity**: توجيه مكثف للمبتدئين و"صمت عميق" للمحترفين لمنع الإرهاق.

### 4. استراتيجية البيانات والتعلم الحافي
*   **Local Personalized AI**: تعلم محلي من مدخلات المستخدم وتحديث الأوزان بدون إنترنت.
*   **Anonymous Value Exchange**: تبادل بصمات مجهولة مقابل ميزات متقدمة لتدريب الذكاء الاصطناعي العالمي.

## هيكلية المستودع المنظمة

*   **`analysis/`**: التحليلات التنافسية، تقييمات الميزات، وقواعد البيانات (بما في ذلك `Hadeed_Master_Database_v3.json`).
*   **`bom/`**: قوائم المواد المحدثة لنسخ V5 Pro Ultra.
*   **`docs/`**: خرائط الطريق، حلول هندسية، وأبحاث المستخدمين (Hadeed Roadmap).
*   **`hardware/`**: تصاميم الـ PCB، أدلة التصنيع، وبروتوكولات BLE.
*   **`archive/`**: الملفات المؤرشفة والنسخ القديمة.

## خطط التحسين المستقبلية
لضمان أعلى معايير الجودة، نتبع خطة تحسين مستمرة تركز على:
1. **التوثيق الموحد**: لسهولة الوصول للمعلومات التقنية.
2. **استراتيجية الاختبار الشامل**: لضمان موثوقية النظام في أصعب الظروف.
3. **خارطة طريق مفصلة**: لتحويل الرؤية إلى واقع ملموس عبر مراحل زمنية محددة.
*يمكن الاطلاع على التفاصيل الكاملة في ملف [IMPROVEMENT_PLAN.md](docs/IMPROVEMENT_PLAN.md).*

## ميثاق المطورين (Developer Commandments)
1. لا تستخدم دالة `Delay` نهائياً (No Blocking Code).
2. إدارة العمليات الحساسة زمنياً عبر `DMA` و `RTOS Preemption`.
3. حماية عمر ذاكرة الـ Flash بالكتابة عند الإطفاء فقط.
4. عزل الحساسات الفاشلة برمجياً لضمان استمرار العمل (Graceful Degradation).
