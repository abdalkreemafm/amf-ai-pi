# بروتوكول التواصل مع تطبيق حديد (BLE)

الجهاز يرسل بايت واحد (HEX) يعبر عن حالة معقدة:

- `0xA1`: هدف ثمين (ذهب/نحاس) - التطبيق ينطق رسالة التحفيز.
- `0xA2`: حديد/خردة - التطبيق يظل صامتاً.
- `0xA3`: ران/تجويف - التطبيق يطلب فتح المسح الثلاثي.
- `0xB1`: سرعة أرجحة عالية - المساعد يطلب التمهل بلطف.
- `0xC1`: بطارية منخفضة < 20% - تفعيل وضع الشبح الموفر.
