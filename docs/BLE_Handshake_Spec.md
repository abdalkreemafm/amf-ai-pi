# بروتوكول المصافحة والتواصل (Hadeed BLE Protocol V7)

## 1. التشفير (Security Layer)
لحماية الجهاز من التقليد، يتم تشفير كافة البيانات باستخدام مفتاح XOR ديناميكي يعتمد على بصمة الجهاز:
- **AES Hint:** `0x5F`
- **Model ID:** `0x55AA`

## 2. المصافحة الأمنية (The Handshake)
عند اتصال التطبيق، يرسل الجهاز تحدياً (Challenge): `[0xDE, 0xAD, 0xBE, 0xEF]`
يجب على التطبيق الرد خلال 1000ms بالمعادلة:
`Response[0] = Challenge[0] ^ 0xAA`
`Response[1] = Challenge[1] ^ 0x55`

## 3. خريطة الأكواد الصوتية (Voice Command Map)
| الكود (Hex) | المعنى التقني | الجملة العاطفية المقترحة |
| :--- | :--- | :--- |
| `0xA0` | ترحيب | "أهلاً بك يا صديقي، عُدنا للبحث عن الكنوز." |
| `0xB0` | ذهب مؤكد | "استعد! رصدتُ هدفاً ثميناً جداً، تمهل!" |
| `0xC0` | ران / فراغ | "انتباه، يوجد ران أو تجويف في هذه الصخرة." |
| `0xE0` | سرعة عالية | "يا صديقي، تمهل قليلاً لكي لا يذهب عملنا سدى." |
| `0xE1` | كويل مرتفع | "أخفض ملف البحث قليلاً لزيادة عمق الاختراق." |

## 4. إطار البيانات ثلاثية الأبعاد (3D Frame Structure)
[SOF][MAG_L][MAG_H][PI_L][PI_H][X_L][X_H][Y_L][Y_H][CRC]
- التردد: 20 إطار في الثانية (20Hz).
